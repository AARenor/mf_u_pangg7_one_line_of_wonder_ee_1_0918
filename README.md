# One line of wonder

This is a small program that writes one short text for make.fun's bounty `u-pangg7-one-line-of-wonder-ee10fcd8`: a single line meant to make a reader feel wonder. It writes `entry.txt` into `MAKEFUN_OUTPUT_DIR` when that is set, falling back to `OUTPUT_DIR` and then `/output`, creating the folder as needed, then prints the character count to standard error.

```text
In the margin of the library book on tides: returned late, still wet.
```

Run it with:

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```
